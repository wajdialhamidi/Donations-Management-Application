# 💝 Donations Management Application

## 📱 Overview
**Donations Management Application** is a simple yet powerful Android application that allows users to make charitable donations seamlessly through **Google Pay integration**.  
The app provides a secure, fast, and user-friendly way for donors to contribute financially and support the organization or cause managed by the app owner.

---

## 🚀 Key Features

### 🙌 For Users
- 💳 **Google Pay Integration** — Donate instantly using your Google Pay account.
- 💰 **Subscription-Based Donations** — Users can contribute fixed or custom amounts as one-time or recurring donations.
- 🔒 **Secure Transactions** — All payments are processed securely through Google’s verified payment gateway.
- 🧾 **Donation History** — Users can view their previous contributions and payment confirmations.
- 🕊️ **Simple & Clean UI** — Easy-to-navigate design for all age groups.

---

### 👨‍💼 For the App Owner
- 📊 **Donor Management** — View and manage all donor information.
- 💸 **Transaction Overview** — Track total donations, daily contributions, and user activity.
- 🔔 **Notifications** — Receive alerts when new donations are made.
- 🔗 **Google Pay Connected** — Automatically handles payment verification and confirmation.

## ⚙️ How It Works
1. The user installs the **Charity Donation App**.
2. The app displays available donation options (monthly, yearly, custom amount).
3. The user selects a payment option and completes the transaction using **Google Pay**.
4. The payment is securely processed and recorded.
5. The app updates the donor’s record and provides a confirmation message.

---

## 🧠 Purpose
This app was built to **simplify the donation process** and encourage charitable giving by providing an accessible, transparent, and reliable payment experience for both donors and organizations.
